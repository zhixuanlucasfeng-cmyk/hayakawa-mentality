# Hayakawa Mentality

A practical Codex skill for turning ambition into calm, disciplined, relationship-aware action, inspired by high-level traits of Hayakawa Aki from *Chainsaw Man*.

It focuses on preparation, steady execution, clear commitments, honest relationships, and regular course correction. It does not imitate the character's violence, self-neglect, revenge, or self-sacrifice.

## Install

Copy this folder into your Codex skills directory:

```sh
cp -R hayakawa-mentality ~/.codex/skills/
```

Then invoke it with `$hayakawa-mentality` or let Codex select it automatically.

## Scope

This is a lightweight reflection and planning framework, not therapy, medical advice, or a promise of success. Adapt it to your actual values, age, responsibilities, and circumstances.
